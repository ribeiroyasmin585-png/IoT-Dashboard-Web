Sobre o Projeto

Este projeto consiste em uma estação de monitoramento IoT capaz de coletar informações ambientais utilizando um ESP32, sensores e comunicação MQTT.

Os dados coletados pelos sensores são enviados através da rede Wi-Fi para um servidor Mosquitto e posteriormente apresentados em um dashboard web em tempo real.

🎯

Objetivo

Monitorar temperatura, umidade e qualidade do ar, apresentando os dados em uma interface web de forma simples, organizada e atualizada em tempo real.

🔧

Hardware

  • ESP32 Dev Module
  • Sensor DHT11
  • Sensor MQ-135
  • LEDs de alerta
🌐

Arquitetura

ESP32 → Wi-Fi → MQTT → Mosquitto → WebSocket → Dashboard Web

Imagens do Projeto

COMUNICAÇÃO

Monitoramento em tempo real

A comunicação entre o ESP32 e o dashboard utiliza o protocolo MQTT. O broker Mosquitto recebe as mensagens enviadas pelo dispositivo e disponibiliza os dados através de WebSockets para a aplicação web.
