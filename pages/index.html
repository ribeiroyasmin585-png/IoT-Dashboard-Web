Sobre o Projeto

Este projeto consiste em uma estação de monitoramento IoT capaz de coletar informações ambientais utilizando um ESP32, sensores e comunicação MQTT.

Os dados coletados são enviados para um servidor Mosquitto e posteriormente apresentados em um dashboard web em tempo real.

🎯 Objetivo

Monitorar temperatura, umidade e qualidade do ar, apresentando os dados em uma interface web de forma simples e atualizada em tempo real.

🔧 Hardware

  • ESP32 Dev Module
  • Sensor DHT11
  • Sensor MQ-135
  • LEDs de alerta

🌐 Arquitetura

ESP32 → Wi-Fi → MQTT → Mosquitto → WebSocket → Dashboard Web
